幻灯片演示

博客系统集成了 Reveal.js，让你可以直接使用 Markdown 创建专业的演示文稿。

两种使用方式

博客系统提供了两种创建幻灯片的方式：

方式目录说明适用场景
独立幻灯片content/slides/专门的幻灯片页面独立演示、可复用内容
文章内幻灯片content/posts/在文章中使用 layout: slides与博客内容结合

方式一：独立幻灯片

在 content/slides/ 目录下创建 .md 文件：

---
title: 我的演示
description: 演示描述
pubDate: 2025-01-05
theme: black
slideNumber: true
---

# 欢迎

这是第一页

---

## 第二页

使用 `---` 分隔幻灯片

---

# 完成！

访问路径：/slides/我的演示

幻灯片列表

访问

基础演示

方式二：文章内幻灯片

在 content/posts/ 目录下的任何位置创建 .md 文件，添加 layout: slides 即可：

---
title: 技术分享
description: 在文章目录中的幻灯片
pubDate: 2025-01-05
tags:
  - 技术
  - 分享
categories:
  - 演示
layout: slides
theme: white
transition: fade
slideNumber: true
---

# 技术分享

这是在 posts 目录中的幻灯片

---

## 功能特点

- 与博客文章在同一目录
- 支持分类和标签
- 会出现在文章列表中

访问路径：/posts/目录/文件名

/posts/test/test-slides 查看实际效果。

Frontmatter 配置

独立幻灯片 (content/slides/)

字段类型默认值说明
titlestring-必填，演示标题
descriptionstring-演示描述
pubDatedate-发布日期
authorstring-作者
tagsarray[]标签列表
themestringblackReveal.js 主题
transitionstringslide过渡动画
controlsbooleantrue显示控制箭头
progressbooleantrue显示进度条
centerbooleantrue内容垂直居中
slideNumberbooleanfalse显示页码
hashbooleantrueURL 包含 hash
draftbooleanfalse草稿状态

文章内幻灯片 (content/posts/)

除了上述字段外，还支持：

字段类型默认值说明
layoutstringdefault设为 slides 启用幻灯片
categoriesarray[]分类（会出现在博客分类中）

完整配置示例

---
title: 产品发布会
description: 2025年新产品发布演示
pubDate: 2025-01-05
author: 产品经理
tags:
  - 产品
  - 发布
categories:
  - 演示
layout: slides        # 关键：启用幻灯片布局
theme: night
transition: fade
controls: true
progress: true
center: true
slideNumber: true
draft: false
---

常见问题

幻灯片不显示？

检查：

  1. 独立幻灯片：文件在 content/slides/ 目录
  2. 文章幻灯片：添加了 layout: slides
  3. Frontmatter 格式正确（--- 包围）
  4. draft 不是 true

layout: slides 不生效？

确保：

  1. 文件在 content/posts/ 目录下
  2. frontmatter 中 layout: slides 正确设置
  3. 重启开发服务器清理缓存

代码高亮不工作？

确保代码块指定了语言：

```javascript
// 正确：指定语言
const x = 1;
```

数学公式不渲染？

使用正确的 LaTeX 语法：

  • 行内：$E = mc^2$
  • 块级：$$公式$$
