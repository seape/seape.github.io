Mermaid 图表

Mermaid 是一个基于文本的图表绘制工具，本博客内置支持，让你可以用简单的语法创建各种图表。

基本语法

在代码块中使用 mermaid 作为语言标识：

```mermaid
graph LR
    A[开始] --> B[结束]
```
🔄 正在渲染 Mermaid 图表...
graph LR
    A[开始] --> B[结束]

流程图 (Flowchart)

基本流程图

🔄 正在渲染 Mermaid 图表...
graph TD
    A[开始] --> B{条件判断}
    B -->|是| C[执行操作A]
    B -->|否| D[执行操作B]
    C --> E[结束]
    D --> E

语法说明：

```mermaid
graph TD
    A[开始] --> B{条件判断}
    B -->|是| C[执行操作A]
    B -->|否| D[执行操作B]
    C --> E[结束]
    D --> E
```

方向控制

方向说明
TB 或 TD从上到下
BT从下到上
LR从左到右
RL从右到左

时序图 (Sequence Diagram)

🔄 正在渲染 Mermaid 图表...
sequenceDiagram
    participant U as 用户
    participant C as 客户端
    participant S as 服务器
    participant D as 数据库

    U->>C: 点击登录
    C->>S: 发送登录请求
    S->>D: 查询用户信息
    D-->>S: 返回用户数据
    S-->>C: 返回登录结果
    C-->>U: 显示登录成功

语法说明：

```mermaid
sequenceDiagram
    participant U as 用户
    participant C as 客户端

    U->>C: 实线箭头
    C-->>U: 虚线箭头
    U-)C: 异步消息
```

全屏预览

对于复杂的图表，元素可能会显示得较小，难以看清细节。本博客提供了全屏预览功能：

使用方法

  1. 鼠标悬停：将鼠标移到图表上，右上角会出现全屏按钮
  2. 点击按钮：点击全屏图标进入全屏预览模式
  3. 缩放操作：
    • 使用工具栏的 + / - 按钮缩放
    • 使用键盘 + / - / 0（重置）快捷键
    • 使用鼠标滚轮缩放
  4. 拖动平移：
    • 按住鼠标左键拖动可平移查看图表不同部分
    • 移动端支持触摸拖动
  5. 退出全屏：点击关闭按钮或按 Esc 键
快捷键与操作
操作功能
+ 或 =放大图表
-缩小图表
0重置为 100%
Esc关闭全屏
鼠标滚轮快速缩放
左键拖动平移图表
适配按钮自动适配屏幕大小

注意：打开全屏时会自动适配屏幕，让图表完整显示在可视区域内。

适用场景

全屏预览特别适合以下场景：

  • 复杂的系统架构图
  • 多参与者的时序图
  • 详细的甘特图计划
  • 包含大量节点的流程图
  • 复杂的实体关系图

注意事项

  • 图表会在页面加载后渲染
  • 复杂图表可能需要几秒钟
  • 语法错误会导致渲染失败
