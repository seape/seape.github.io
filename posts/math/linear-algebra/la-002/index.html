向量的深入理解

向量的数学定义

向量是一个有序的数组，通常表示为： v=[v1v2⋮vn]\mathbf{v} = \begin{bmatrix} v_1 \\ v_2 \\ \vdots \\ v_n \end{bmatrix}v=​v1​v2​⋮vn​​​

其中 viv_ivi​ 是向量的第 iii 个分量。

向量空间的公理化定义

向量空间（线性空间）是一个集合 VVV，其元素称为向量，满足以下公理：

加法公理

设 u,v,w∈V\mathbf{u}, \mathbf{v}, \mathbf{w} \in Vu,v,w∈V：

  1. 封闭性: u+v∈V\mathbf{u} + \mathbf{v} \in Vu+v∈V
  2. 交换律: u+v=v+u\mathbf{u} + \mathbf{v} = \mathbf{v} + \mathbf{u}u+v=v+u
  3. 结合律: (u+v)+w=u+(v+w)(\mathbf{u} + \mathbf{v}) + \mathbf{w} = \mathbf{u} + (\mathbf{v} + \mathbf{w})(u+v)+w=u+(v+w)
  4. 零元素: 存在 0∈V\mathbf{0} \in V0∈V，使得 v+0=v\mathbf{v} + \mathbf{0} = \mathbf{v}v+0=v
  5. 负元素: 对每个 v∈V\mathbf{v} \in Vv∈V，存在 −v∈V-\mathbf{v} \in V−v∈V，使得 v+(−v)=0\mathbf{v} + (-\mathbf{v}) = \mathbf{0}v+(−v)=0

数乘公理

设 a,ba, ba,b 为标量，u,v∈V\mathbf{u}, \mathbf{v} \in Vu,v∈V：

  1. 封闭性: av∈Va\mathbf{v} \in Vav∈V
  2. 分配律1: a(u+v)=au+ava(\mathbf{u} + \mathbf{v}) = a\mathbf{u} + a\mathbf{v}a(u+v)=au+av
  3. 分配律2: (a+b)v=av+bv(a + b)\mathbf{v} = a\mathbf{v} + b\mathbf{v}(a+b)v=av+bv
  4. 结合律: (ab)v=a(bv)(ab)\mathbf{v} = a(b\mathbf{v})(ab)v=a(bv)
  5. 单位元: 1v=v1\mathbf{v} = \mathbf{v}1v=v
# 验证向量空间公理
def verify_vector_space_axioms():
    # 定义一些向量
    u = np.array([1, 2, 3])
    v = np.array([4, 5, 6])
    w = np.array([7, 8, 9])
    zero = np.array([0, 0, 0])

    # 标量
    a, b = 2, 3

    print("验证向量空间公理:")
    print("=" * 40)

    # 加法交换律
    print(f"1. 交换律: u + v = {u + v}")
    print(f"           v + u = {v + u}")
    print(f"   相等? {np.array_equal(u + v, v + u)}")

    # 加法结合律
    print(f"\n2. 结合律: (u + v) + w = {(u + v) + w}")
    print(f"           u + (v + w) = {u + (v + w)}")
    print(f"   相等? {np.array_equal((u + v) + w, u + (v + w))}")

    # 零向量
    print(f"\n3. 零向量: u + 0 = {u + zero}")
    print(f"           u = {u}")
    print(f"   相等? {np.array_equal(u + zero, u)}")

    # 负向量
    neg_u = -u
    print(f"\n4. 负向量: u + (-u) = {u + neg_u}")
    print(f"   是否为零? {np.allclose(u + neg_u, zero)}")

    # 数乘分配律
    print(f"\n5. 数乘分配律1: a(u + v) = {a * (u + v)}")
    print(f"                au + av = {a * u + a * v}")
    print(f"   相等? {np.array_equal(a * (u + v), a * u + a * v)}")

    print(f"\n6. 数乘分配律2: (a + b)u = {(a + b) * u}")
    print(f"                au + bu = {a * u + b * u}")
    print(f"   相等? {np.array_equal((a + b) * u, a * u + b * u)}")

verify_vector_space_axioms()

子空间理论

子空间的定义

向量空间 VVV 的子集 WWW 称为 VVV 的子空间，如果 WWW 本身也是向量空间。

子空间判定定理

WWW 是 VVV 的子空间当且仅当：

  1. 0∈W\mathbf{0} \in W0∈W（包含零向量）
  2. 对任意 u,v∈W\mathbf{u}, \mathbf{v} \in Wu,v∈W，有 u+v∈W\mathbf{u} + \mathbf{v} \in Wu+v∈W（加法封闭）
  3. 对任意 c∈Rc \in \mathbb{R}c∈R，v∈W\mathbf{v} \in Wv∈W，有 cv∈Wc\mathbf{v} \in Wcv∈W（数乘封闭）
def is_subspace(vectors, test_vectors=None):
    """
    检验给定向量组是否张成一个子空间
    """
    vectors = np.array(vectors)

    # 检查是否包含零向量
    zero_vector = np.zeros(vectors.shape[1])
    contains_zero = any(np.allclose(v, zero_vector) for v in vectors)

    print(f"包含零向量: {contains_zero}")

    # 检查加法封闭性（简单测试）
    if len(vectors) >= 2:
        v1, v2 = vectors[0], vectors[1]
        sum_vector = v1 + v2
        print(f"v1 + v2 = {sum_vector}")

    # 检查数乘封闭性
    if len(vectors) >= 1:
        v1 = vectors[0]
        scaled = 2 * v1
        print(f"2 * v1 = {scaled}")

    return contains_zero

# 示例1: R^3中通过原点的直线
print("示例1: 通过原点的直线 span{(1,2,3)}")
line_vectors = [np.array([0, 0, 0]), np.array([1, 2, 3]), np.array([2, 4, 6])]
is_subspace(line_vectors)

print("\n" + "="*50)

# 示例2: R^3中通过原点的平面

                 np.array([0, 1, 0]), np.array([1, 1, 0])]

本章小结

本章深入探讨了向量空间的基础理论：

概念核心内容重要性质
向量运算加法、数乘满足交换律、结合律、分配律
向量空间10个公理抽象化的线性结构
子空间3个判定条件包含零向量、运算封闭
零向量加法单位元唯一性、中性作用
负向量加法逆元每个向量都有唯一负向量
重要提醒
  • 向量空间的公理是抽象的，但适用于各种具体的数学对象
  • 子空间必须包含零向量，这是判定的必要条件
  • 理解几何直观有助于掌握抽象概念

通过本章学习，我们建立了严格的向量空间理论基础，为后续学习线性相关性、基与维数等概念做好了准备。
