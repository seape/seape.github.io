第3章 基础建模技术

作者
2024年1月3日
约 6 分钟阅读
#多边形建模 #网格编辑 #建模工具

第3章 基础建模技术

学习目标
  • 掌握基本几何体的创建和编辑
  • 学会顶点、边、面的编辑操作
  • 理解网格拓扑结构
  • 掌握挤出、内插、倒角等基础工具
  • 学会使用修改器进行参数化建模

知识点详解

3.1 多边形建模基础

3.1.1 网格结构

多边形网格由三个基本元素组成：

顶点 (Vertices) - 点
    ↓
边 (Edges) - 连接两个顶点的线
    ↓  
面 (Faces) - 由边围成的多边形

网格特性：

  • 顶点：定义形状的基本点，具有位置信息
  • 边：连接顶点，定义形状轮廓
  • 面：封闭区域，用于渲染和显示
面的类型
  • 三角面 (Tris)：最基础的面，渲染效率高
  • 四边面 (Quads)：建模首选，易于细分和编辑
  • 多边面 (N-gons)：5个或更多边的面，通常需要避免

3.1.2 基本几何体

添加基础几何体：

Shift + A → Mesh  # 打开网格菜单

基础几何体列表：
- Plane：平面 (4顶点)
- Cube：立方体 (8顶点)
- Circle：圆形 (默认32顶点)
- UV Sphere：UV球 (经纬度球体)
- Ico Sphere：二十面球 (三角面球体)
- Cylinder：圆柱 (默认32边)
- Cone：圆锥
- Torus：环面

几何体参数设置：

# 添加后在左下角或按F9调出参数面板
Vertices：顶点数 (圆形、圆柱等)
Radius：半径
Depth：深度 (圆柱高度)
Location：位置
Rotation：旋转

3.2 编辑模式基础

3.2.1 编辑模式切换

Tab  # 物体模式 ↔ 编辑模式

# 编辑模式下的选择类型切换
1  # 顶点选择模式 (或 Ctrl+Tab 菜单)
2  # 边选择模式
3  # 面选择模式

# 组合选择模式
Shift + 1/2/3  # 同时启用多种选择模式

3.2.2 基础选择操作

选择工具：

# 基础选择
左键点击  # 选择单个元素
Shift + 左键  # 添加/移除选择
A  # 全选
Alt + A  # 取消全选
Ctrl + I  # 反选

# 扩展选择
Ctrl + +  # 扩展选择
Ctrl + -  # 收缩选择

# 循环选择
Alt + 左键  # 选择边循环
Ctrl + Alt + 左键  # 选择面环

选择相似：

Shift + G  # 选择相似菜单
- Vertex Groups：顶点组
- Co-planar：共面
- Area：面积相似
- Sides：边数相似
- Material：相同材质

3.3 基础编辑工具

3.3.1 挤出工具 (Extrude)

挤出是建模中最重要的工具之一：

E  # 挤出选中的面/边/顶点

# 挤出变体
E + X/Y/Z  # 沿轴挤出
E + S  # 挤出并缩放

# 特殊挤出
Alt + E  # 挤出菜单
- Extrude Region：区域挤出
- Extrude Individual Faces：独立面挤出
- Extrude to Cursor：挤出到游标

挤出应用示例：

# 制作简单房屋
1. 添加立方体
2. Tab 进入编辑模式
3. 3 切换到面选择模式
4. 选择顶面
5. E 挤出，Z 约束到垂直方向，输入0.5
6. S 缩放到0.8创建屋顶边缘
7. E 再次挤出向上0.3创建屋顶

3.3.2 内插面 (Inset)

I  # 内插面工具

# 内插选项
I + I  # 独立面内插
I + O  # 外向内插

# 内插时的操作
- 鼠标移动：调节内插距离
- Ctrl：启用均匀模式
- O：切换外向内插

3.3.3 倒角工具 (Bevel)

Ctrl + B  # 倒角选中的边/顶点

# 倒角控制
- 鼠标移动：调节倒角大小
- 滚轮：增加/减少分段数
- Ctrl：启用捕捉
- Shift：精确调节

倒角应用：

# 创建圆滑的立方体
1. 选择立方体的所有边（Alt + A, 然后 2 切换到边模式, A）
2. Ctrl + B 倒角
3. 滚轮增加分段数到 3-4
4. 调节大小到合适值

3.4 高级编辑工具

3.4.1 环切和分割

环切 (Loop Cut)：

Ctrl + R  # 环切工具
- 鼠标移动：选择切割位置
- 滚轮：增加切割数量
- 确认：左键点击
- 滑动：鼠标移动调节位置

刀切工具 (Knife)：

K  # 刀切工具
- 左键：创建切点
- Enter：确认切割
- Esc：取消

K + C  # 约束刀切（仅45度角等）

3.4.2 合并和溶解

合并顶点：

Alt + M  # 合并菜单
- At Center：到中心点
- At Cursor：到游标位置
- Collapse：塌陷
- At First/Last：到首/尾顶点

溶解元素：

Ctrl + X  # 删除/溶解菜单
- Vertices：删除顶点
- Dissolve Vertices：溶解顶点
- Edge Loops：删除边循环
- Faces：删除面

3.4.3 细分和平滑

细分：

# 右键菜单或工具栏
Subdivide  # 细分选中面
- Number of Cuts：切割数
- Smoothness：平滑度
- Fractal：分形效果

平滑：

# 右键菜单
Smooth  # 平滑顶点
Shade Smooth  # 平滑着色
Shade Flat  # 平面着色

3.5 修改器系统

3.5.1 修改器概念

修改器是非破坏性的建模工具，可以实时预览效果：

原始网格 → 修改器1 → 修改器2 → 最终结果

修改器特点：

  • 非破坏性编辑
  • 可堆叠使用
  • 实时预览
  • 可随时调节参数

3.5.2 常用建模修改器

镜像修改器 (Mirror)：

# 添加镜像修改器
Properties Panel → Modifier Properties → Add Modifier → Mirror

主要参数：
- Axis：镜像轴 (X/Y/Z)
- Bisect：切分原网格
- Merge：合并中心线顶点

阵列修改器 (Array)：

# 阵列参数
Count：副本数量
Relative Offset：相对偏移
Constant Offset：固定偏移
Object Offset：使用物体偏移

细分曲面修改器 (Subdivision Surface)：

# 细分参数  
Levels Viewport：视口级别
Render：渲染级别
Type：细分类型 (Catmull-Clark/Simple)

3.6 建模工作流程

3.6.1 阻塞建模法 (Blockout Modeling)

# 第一步：创建基本形状
1. 从简单几何体开始
2. 使用挤出创建基本轮廓
3. 不关注细节，只做大形

# 第二步：细化形状
4. 添加必要的环切
5. 调节顶点位置
6. 使用倒角添加细节

# 第三步：优化拓扑
7. 确保四边面为主
8. 保持良好的边流
9. 避免多边形和三角形

3.6.2 参考图建模

# 设置参考图
1. Shift + A → Empty → Image
2. 在属性面板加载参考图片
3. 调节透明度和位置
4. 在多个视图设置不同参考图

# 按参考图建模
5. 从侧视图开始建模
6. 逐步在不同视图调节
7. 保持与参考图的对应关系

3.7 实战练习

练习1：基础家具建模

练习目标

掌握基础建模工具的综合运用

# 制作一把简单椅子
# 椅座制作：
1. 添加立方体
2. S + Z + 0.1 (压扁作为座面)  
3. S + X + 0.8, S + Y + 0.8 (调节座面大小)

# 椅背制作：
4. E 挤出顶面
5. S + Y + 0.1 (压薄作为椅背)
6. G + Z + 0.8 (向上移动椅背)

# 椅腿制作：
7. 进入编辑模式，选择底面四个角的顶点
8. E 挤出向下
9. S + 0.1 (缩小作为椅腿)

练习2：有机形状建模

# 制作简单花瓶
1. 添加圆柱体 (Vertices: 12)
2. Tab 进入编辑模式
3. Alt + A 取消全选, 然后 3 (面选择模式)
4. 选择顶面，Delete 删除
5. 2 切换到边选择模式
6. Alt + 左键 选择顶部边环
7. Ctrl + R 添加多个环切 (滚轮调节数量到5-6)
8. 在不同高度选择边环
9. S 缩放不同边环创建花瓶轮廓
10. 选择底部边环，E 挤出，S + 0 合并创建底部

练习3：修改器应用

注意事项
  • 修改器的顺序很重要
  • 应用修改器前要谨慎考虑
  • 镜像建模时注意物体的中心位置
# 制作对称的装饰品
1. 添加立方体
2. Tab 进入编辑模式
3. 选择右半部分的顶点并删除
4. 添加镜像修改器 (Axis: X)
5. 建模时只编辑一侧，另一侧自动镜像
6. 使用挤出和倒角创建细节
7. 完成后可以应用镜像修改器

# 创建阵列装饰
8. 选择完成的装饰品
9. 添加阵列修改器
10. 设置Count为5，调节偏移距离
11. 创建一排装饰品

3.8 拓扑结构最佳实践

3.8.1 良好拓扑的特征

四边形优先：

✓ 四边形网格：
□─□─□
│ │ │
□─□─□
│ │ │  
□─□─□

✗ 混乱拓扑：
△─□─◇
│/│\│
□─◇─△

边流方向：

  • 边应该跟随形状的自然流向
  • 圆形区域使用径向边流
  • 肌肉和形变区域需要合适的边流

3.8.2 拓扑优化技巧

# 减少多边形
1. 选择多边形面
2. Mesh → Faces → Triangulate Faces  # 三角化
3. 手动合并相邻边和顶点

# 增加分辨率  
1. 选择需要细分的区域
2. 右键 → Subdivide
3. 或使用环切添加边环

# 重新拓扑
1. 创建新的网格覆盖在原模型上
2. 使用Retopo功能对齐到原模型表面
3. 保持良好的四边形结构

3.9 常用建模快捷键

工具快捷键说明
挤出E挤出面/边/顶点
内插I内插面
倒角Ctrl + B倒角边/顶点
环切Ctrl + R环切工具
刀切K刀切工具
合并Alt + M合并顶点
分离P分离为新物体
连接J连接顶点
填充F填充面
细分Ctrl + 1-4应用细分层级

建模工具总结

3.10 工具栏工具

在编辑模式的工具栏中：

选择工具：
- 选择框 (B)
- 选择圈 (C)
- 套索选择

基础工具：
- 挤出 (E)
- 内插 (I)  
- 倒角 (Ctrl+B)
- 刀切 (K)
- 环切 (Ctrl+R)

高级工具：
- PolyBuild：交互式建模
- Edge Split：边分割
- Spin：旋转复制
- Screw：螺旋工具
学习建议
  1. 从简单开始：先掌握基本工具，再学习高级技巧
  2. 理解拓扑：良好的拓扑是后续操作的基础
  3. 多做练习：建模需要大量实践才能熟练
  4. 参考现实：观察真实物体的形状和结构
  5. 保持整洁：定期清理无用顶点和边

通过本章学习，你应该能够：

  • 熟练使用基础建模工具
  • 理解网格拓扑的重要性
  • 创建中等复杂度的模型
  • 合理使用修改器系统

这些技能是所有复杂建模工作的基础，必须反复练习直到熟练掌握。
