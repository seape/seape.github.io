第1章 Blender入门基础

学习目标
  • 了解 Blender 软件概述和应用领域
  • 掌握 Blender 界面布局和基本操作
  • 学会基础导航和视图控制
  • 理解 Blender 工作流程概念
  • 掌握文件管理和项目设置

知识点详解

1.1 Blender 软件概述

1.1.1 什么是 Blender

Blender 是一款功能完整的开源 3D 创作套件，支持整个 3D 管道流程：建模、雕刻、动画、模拟、渲染、合成和运动跟踪。它还具备视频编辑和游戏创作功能。

核心特性：

  • 完全免费且开源
  • 跨平台支持（Windows、macOS、Linux）
  • 活跃的开发社区
  • 定期更新和功能改进
  • 不限制商业使用

1.1.2 应用领域

应用领域具体用途案例
影视制作特效、动画、建模《Spider-Man: Into the Spider-Verse》部分场景
游戏开发角色建模、场景制作、动画独立游戏开发
建筑可视化建筑渲染、室内设计建筑设计预览
产品设计工业设计、产品展示产品原型展示
教育培训3D 教学、科学可视化教育动画制作

1.2 Blender 界面布局

1.2.1 默认界面组成

┌─────────────────────────────────────────────┐
│              菜单栏 (Menu Bar)                │
├─────────┬─────────────────┬─────────────────┤
│         │                 │                 │
│  大纲   │    3D 视口      │   属性面板      │
│ 编辑器  │   (3D Viewport) │ (Properties)    │
│(Outliner)│                │                 │
│         │                 │                 │
├─────────┼─────────────────┤                 │
│         │                 │                 │
│  着色器 │    时间轴       │                 │
│ 编辑器  │  (Timeline)     │                 │
│(Shader) │                 │                 │
└─────────┴─────────────────┴─────────────────┘

1.2.2 主要编辑器介绍

3D 视口 (3D Viewport)：

  • 主要工作区域
  • 显示 3D 场景
  • 支持多种着色模式
  • 提供多种选择和变换工具

大纲编辑器 (Outliner)：

  • 显示场景层级结构
  • 管理物体可见性和选择状态
  • 组织场景元素

属性面板 (Properties Panel)：

  • 显示选中物体的详细设置
  • 包含多个子面板（物体、材质、渲染等）
  • 提供参数调节功能

着色器编辑器 (Shader Editor)：

  • 创建和编辑材质
  • 基于节点的工作流程
  • 支持复杂材质制作

1.3 基础导航和视图控制

1.3.1 视口导航

鼠标操作规则

Blender 使用三键鼠标操作模式：

  • 左键：选择物体
  • 中键：视口导航（旋转、缩放、平移）
  • 右键：弹出上下文菜单

基本导航操作：

视图旋转：中键拖拽
视图缩放：滚轮滚动
视图平移：Shift + 中键拖拽

数字键盘快捷操作：
- 1：前视图
- 3：右视图  
- 7：顶视图
- 0：摄像机视图
- 5：正交/透视切换
- . (句号)：聚焦到选中物体

1.3.2 选择操作

选择方式：

  • 点击选择：左键点击物体
  • 框选：B 键激活，拖拽选择区域
  • 套索选择：Ctrl + 左键拖拽
  • 全选/取消全选：A 键 / Alt + A

多选操作：

Shift + 左键：添加到选择
Shift + 右键：从选择中移除
Ctrl + I：反向选择

1.4 基本物体操作

1.4.1 添加物体

添加基本几何体：

Shift + A：打开添加菜单
- Mesh（网格）
  - Cube（立方体）
  - UV Sphere（UV 球体）
  - Cylinder（圆柱体）
  - Plane（平面）
  - 等等...

1.4.2 变换操作

基本变换工具：

操作快捷键说明
移动 (Grab)G移动物体位置
旋转 (Rotate)R旋转物体
缩放 (Scale)S改变物体大小

约束轴向操作：

# 示例：精确移动操作
G + X + 2  # 沿 X 轴移动 2 个单位
R + Z + 45 # 沿 Z 轴旋转 45 度
S + Y + 2  # 沿 Y 轴缩放 2 倍

# 约束到平面
G + Shift + Z  # 在 XY 平面移动（排除 Z 轴）

1.4.3 删除和撤销

删除操作：
- Delete/X：删除选中物体
- Ctrl + Z：撤销
- Ctrl + Shift + Z：重做

1.5 编辑模式基础

1.5.1 编辑模式切换

Tab：在物体模式和编辑模式间切换
Ctrl + Tab：快速切换编辑模式类型

编辑模式下的选择类型：

  • 顶点模式：选择和编辑顶点
  • 边模式：选择和编辑边
  • 面模式：选择和编辑面

1.5.2 基础编辑操作

挤出操作 (Extrude)：

# 挤出选中的面
E  # 激活挤出工具
# 然后移动鼠标定位新位置
# 左键确认，右键取消

# 示例：创建一个简单的房子
# 1. 添加立方体
# 2. 进入编辑模式（Tab）
# 3. 选择顶面（Alt + 3 切换到面选择模式）
# 4. 按 E 挤出顶面
# 5. 按 S 缩放到合适大小作为屋顶

1.6 工作区和界面定制

1.6.1 预设工作区

Blender 提供多个预设工作区：

工作区用途主要编辑器
Layout通用布局3D 视口、大纲、属性
Modeling建模专用3D 视口、修改器属性
Sculpting雕刻专用3D 视口、雕刻工具
UV EditingUV 编辑UV 编辑器、3D 视口
Texture Paint纹理绘制3D 视口、图像编辑器
Shading材质制作3D 视口、着色器编辑器
Animation动画制作3D 视口、时间轴、摄影表
Rendering渲染设置3D 视口、渲染属性

1.6.2 界面定制

分割编辑器：

右键点击编辑器边框 → 分割区域
拖拽创建新的编辑器区域

合并编辑器：

右键点击编辑器边框 → 合并区域
选择要保留的编辑器

1.7 文件管理

1.7.1 文件操作

基本文件操作：

Ctrl + N：新建文件
Ctrl + O：打开文件
Ctrl + S：保存文件
Ctrl + Shift + S：另存为
Ctrl + Z：撤销

1.7.2 项目管理最佳实践

项目组织建议
项目文件夹结构：
MyProject/
├── Blends/          # Blender 文件
├── Textures/        # 纹理文件
├── References/      # 参考图像
├── Renders/         # 渲染输出
└── Assets/          # 其他资源

文件保存设置：

# 启用自动保存（在用户偏好设置中）
File → Preferences → Save & Load
- Auto Save Temporary Files: 启用
- Timer (minutes): 设置自动保存间隔

1.8 偏好设置

1.8.1 重要设置项

输入设置：

Edit → Preferences → Input
- Select With: 选择鼠标左键还是右键
- Emulate 3 Button Mouse: 模拟三键鼠标
- Emulate Numpad: 模拟数字键盘

主题设置：

Edit → Preferences → Themes
- 选择不同的界面主题
- 自定义颜色方案

插件管理：

Edit → Preferences → Add-ons
- 启用/禁用内置插件
- 安装第三方插件

1.9 实战练习

练习1：界面熟悉练习

练习步骤
  1. 打开 Blender，熟悉默认界面
  2. 尝试使用鼠标导航（旋转、缩放、平移）
  3. 使用数字键盘切换不同视图
  4. 练习选择和取消选择默认立方体
  5. 尝试切换不同的工作区

练习2：基础建模练习

# 制作简单的雪人
# 步骤：
# 1. 删除默认立方体（Delete 键）
# 2. 添加 UV 球体作为身体（Shift + A → Mesh → UV Sphere）
# 3. 复制球体作为头部（Shift + D）
# 4. 缩放头部并移动到合适位置（S 缩放，G 移动）
# 5. 添加更小的球体作为眼睛和鼻子
# 6. 保存文件（Ctrl + S）

练习3：基础编辑练习

注意事项

在编辑模式下：

  • 确保选择正确的组件类型（顶点/边/面）
  • 挤出操作后需要移动到新位置
  • 经常使用 Tab 键在物体模式和编辑模式间切换
# 制作简单的房屋模型
# 1. 从立方体开始
# 2. 进入编辑模式（Tab）
# 3. 选择顶面
# 4. 挤出顶面（E）
# 5. 内插面（I）创建屋顶边缘
# 6. 挤出创建屋顶
# 7. 添加门窗（删除面，挤出内陷）

常用快捷键总结

功能快捷键说明
选择全部/取消A / Alt+A全选或取消选择
删除X / Delete删除选中物体
移动G抓取移动
旋转R旋转物体
缩放S缩放物体
挤出E挤出面/边
切换编辑模式Tab物体模式↔编辑模式
添加物体Shift+A添加菜单
撤销/重做Ctrl+Z / Ctrl+Shift+Z撤销和重做
保存Ctrl+S保存文件
学习建议
  1. 多练习导航：熟练的视口导航是 3D 工作的基础
  2. 记忆快捷键：快捷键能显著提高工作效率
  3. 理解模式切换：物体模式和编辑模式的区别很重要
  4. 建立良好习惯：定期保存，合理组织文件结构
  5. 循序渐进：不要急于求成，打好基础很重要

通过本章学习，你应该能够：

  • 熟练导航 Blender 界面
  • 理解基本的 3D 操作概念
  • 完成简单的物体创建和编辑
  • 建立良好的工作习惯

这些基础技能将为后续更高级的学习奠定坚实基础。
