1. Asking a Librarian for Help with a Broken Photocopier 图书馆复印机坏了 #221001 极高频 极限预测 简单

You were trying to photocopy a document at the library, but you find the photocopier not working and there is a flashing light next to the photocopy icon. You want to ask the librarian to help you. What would you say?

你当时正在图书馆里试图复印一份文件，但发现复印机无法正常工作，而且复印图标旁边还闪烁着指示灯。你想向图书馆管理员寻求帮助。你会怎么说？

Sample Answer

Excuse me! I was trying to photocopy a document, but it seems the machine isn’t working. There’s a flashing light next to the photocopy icon, but I don’t know how to fix it. Could you please help me with it? Thanks a lot!

Template Answer

Hi, do you have a moment?
I’d like to talk to you about the photocopier at the library.
The situation is that I was trying to photocopy a document, but I found the photocopier not working and there is a flashing light next to the photocopy icon.
This is important because I need to photocopy this document urgently.
I was wondering if you could help me with it.
I’d really appreciate it.

photocopier /ˈfoʊtəˌkɑːpiər/ n. 复印机
