## 备考阶段

### 第一阶段：基础夯实（第 1-4 周）
- 重点：RA、RS、WFD 核心题型
- 目标：熟悉题型，建立发音基础

### 第二阶段：强化提升（第 5-8 周）
- 重点：全题型涉猎，均衡训练
- 目标：技巧训练，提升速度

### 第三阶段：冲刺突破（第 9-12 周）
- 重点：机经冲刺，高频预测
- 目标：查漏补缺，模考冲刺
