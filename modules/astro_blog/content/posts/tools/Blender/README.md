<!-- # Blender 3D建模与动画完整课程 -->

## 第 1 章：Blender入门基础
学习目标：
1. 了解 Blender 软件概述和应用领域
2. 掌握 Blender 界面布局和基本操作
3. 学会基础导航和视图控制
4. 理解 Blender 工作流程概念
5. 掌握文件管理和项目设置

简要说明：建立对 Blender 的整体认知，熟悉软件环境，为后续学习奠定基础。

## 第 2 章：3D基础概念与坐标系统
学习目标：
1. 理解 3D 空间坐标系统
2. 掌握物体的变换操作（移动、旋转、缩放）
3. 学会物体的选择和编辑模式
4. 理解局部坐标系与全局坐标系
5. 掌握精确建模工具和对齐功能

简要说明：建立 3D 思维，掌握空间操作的基础概念和精确控制方法。

## 第 3 章：基础建模技术
学习目标：
1. 掌握基本几何体的创建和编辑
2. 学会顶点、边、面的编辑操作
3. 理解网格拓扑结构
4. 掌握挤出、内插、倒角等基础工具
5. 学会使用修改器进行参数化建模

简要说明：掌握多边形建模的核心技术，能够创建简单到中等复杂度的 3D 模型。

## 第 4 章：高级建模技术
学习目标：
1. 掌握细分曲面建模
2. 学会雕刻模式的使用
3. 理解拓扑重构技术
4. 掌握布尔运算和程序化建模
5. 学会硬表面和有机体建模方法

简要说明：提升建模技能，能够处理复杂模型的创建和优化。

## 第 5 章：材质系统与着色器
学习目标：
1. 理解材质和着色器节点系统
2. 掌握 PBR（基于物理渲染）材质制作
3. 学会纹理映射和 UV 展开
4. 掌握程序化材质制作
5. 理解光照模型和材质交互

简要说明：掌握材质制作的完整流程，能够创建真实感和风格化材质。

## 第 6 章：纹理制作与UV映射
学习目标：
1. 掌握 UV 展开技术和最佳实践
2. 学会纹理绘制和外部软件集成
3. 理解纹理类型和用途（漫反射、法线、粗糙度等）
4. 掌握纹理烘焙技术
5. 学会纹理优化和管理

简要说明：完善材质制作技能，掌握高质量纹理的制作和应用方法。

## 第 7 章：光照与渲染设置
学习目标：
1. 理解不同类型的光源和特性
2. 掌握三点布光等经典布光技法
3. 学会 HDRI 环境光照的使用
4. 理解渲染引擎（Cycles、Eevee）的特点
5. 掌握渲染设置和优化技术

简要说明：掌握光照艺术，能够为场景创建合适的光照环境和渲染设置。

## 第 8 章：动画基础与关键帧
学习目标：
1. 理解动画原理和时间轴概念
2. 掌握关键帧动画制作
3. 学会插值和缓动曲线调节
4. 掌握路径动画和约束系统
5. 理解动画图表编辑器的使用

简要说明：掌握动画制作的基础技能，能够创建流畅的物体动画。

## 第 9 章：角色绑定与骨骼系统
学习目标：
1. 理解骨骼系统和层级关系
2. 掌握骨骼创建和绑定技术
3. 学会权重绘制和变形调整

5. 理解控制器和约束的应用

简要说明：掌握角色动画的技术基础，能够为角色创建可动画的绑定系统。

## 第 10 章：角色动画与表演
