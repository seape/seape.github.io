# PTE 评分标准与实用技巧

## Speaking 评分标准

### Read Aloud (RA) 评分标准

Read Aloud 是 PTE 口语部分最重要的题型，同时贡献 Speaking 和 Reading 分数。

#### 三个评分维度

| 维度 | 评分内容 | 最高分 |
|------|---------|--------|
| **Content（内容）** | 是否按顺序正确朗读每个单词 | 5 分 |
| **Pronunciation（发音）** | 发音是否接近母语者标准 | 5 分 |
| **Oral Fluency（流利度）** | 是否流畅、无不必要停顿或自我纠正 | 5 分 |

#### 评分细则

:::tabs
@tab Content 内容

**评分范围：0-5 分**

| 分数 | 标准 |
|------|------|
| **5 分** | 所有单词正确朗读，顺序正确 |
| **4 分** | 漏读/错读 1-2 个词 |
| **3 分** | 漏读/错读 3-4 个词 |
| **2 分** | 漏读/错读较多词 |
| **0 分** | 完全没读或全部错误 |

> 💡 按顺序读完所有单词即可得满分，跳过 1-2 个难词影响不大

@tab Pronunciation 发音

**评分范围：0-5 分**

| 分数 | 标准 |
|------|------|
| **5 分** | 所有元音、辅音发音准确，重音正确 |
| **4 分** | 大部分发音正确，少数错误不影响理解 |
| **3 分** | 部分发音有问题，但仍可理解 |
| **2 分** | 发音问题较多，理解困难 |
| **0 分** | 无法理解 |

> 💡 元音发饱满，辅音不吞音，注意单词重音和句子重音

@tab Oral Fluency 流利度

**评分范围：0-5 分**

| 分数 | 标准 |
|------|------|
| **5 分** | 语速自然，无明显停顿，节奏流畅 |
| **4 分** | 基本流畅，有少量犹豫 |
| **3 分** | 有明显停顿或重复 |
| **2 分** | 频繁停顿，语速不稳定 |
| **0 分** | 无法完成朗读 |

> 💡 保持自然语速，读错不要回读，根据意群合理停顿

:::

#### 分数贡献

Read Aloud 同时贡献两个分数：
- **Speaking 分数**：约占 25-30%
- **Reading 分数**：约占 20-30%

::: warning 2025年8月更新

根据 Pearson 2025 年 8 月 7 日的更新：
- Read Aloud 不再贡献 Reading 分数
- RA 的整体权重有所降低
:::

#### RA 实用技巧

:::tabs
@tab 发音技巧

**提升发音质量的关键要点**

| 技巧 | 说明 |
|------|------|
| 元音饱满 | 元音发饱满，辅音不吞音 |
| 自然连读 | 该连读就连读，保持流畅 |
| 意群停顿 | 根据意群合理停顿，不随意断句 |
| 重读关键词 | 重读主语、谓语、宾语、状语 |

> 💡 录音回听是提升发音的最有效方法

@tab 避免扣分

**常见扣分陷阱及应对策略**

| 错误行为 | 正确做法 |
|----------|----------|
| 回读纠错 | 读错了继续往下读，不要回头 |
| 遇词卡壳 | 遇到生词根据拼读规则大胆读出来 |
| 语速不当 | 保持自然语速，不要太快或太慢 |
| 跳词过多 | 跳过 5 个词以内通常不会严重影响分数 |

> ⚠️ 流利度比完美发音更重要，保持自信流畅地朗读

:::

## Reading 评分标准

PTE 阅读部分包含多种题型，每种题型的评分方式不同。

### 题型与分值

| 题型 | 题目数量 | 评分方式 | 分值贡献 |
|------|---------|---------|---------|
| **Reading & Writing: Fill in the Blanks (RW-FIB)** | 5-6 题 | 部分得分 | Reading + Writing |
| **Multiple Choice, Multiple Answers (MC-MA)** | 2-3 题 | 部分得分（错选扣分） | Reading |
| **Re-order Paragraphs (RO)** | 2-3 题 | 部分得分 | Reading |
| **Reading: Fill in the Blanks (R-FIB)** | 4-5 题 | 部分得分 | Reading |
| **Multiple Choice, Single Answer (MC-SA)** | 2-3 题 | 全对得分 | Reading |

### 各题型评分与技巧

:::tabs
@tab RW-FIB

**Reading & Writing: Fill in the Blanks**

**评分规则**：
- 每个空格正确 +1 分
- 错误或不填 0 分
- **同时贡献 Reading 和 Writing 分数**

**策略建议**：

| 要点 | 说明 |
|------|------|
| 重要程度 | 最重要的阅读题型，同时影响两个分数 |
| 解题顺序 | 先看选项，再读文章 |
| 关注点 | 注意词性、搭配和语法 |

> 💡 这是性价比最高的题型，务必认真对待

@tab MC-MA

**Multiple Choice, Multiple Answers**

**评分规则**：
- 选对一个 +1 分
- 选错一个 -1 分
- 最低 0 分（不会负分）

**策略建议**：

| 原则 | 说明 |
|------|------|
| 谨慎选择 | 不确定的选项不要选 |
| 少选为上 | 宁可少选，不要错选 |
| 答案数量 | 通常正确答案 2-3 个 |

> ⚠️ 错选会倒扣分，宁缺勿滥

@tab RO

**Re-order Paragraphs**

**评分规则**：
- 按照相邻配对计分
- 每个正确的相邻配对 +1 分
- 例如：5 段文字，最多 4 个相邻配对，最高 4 分

**策略建议**：

| 步骤 | 方法 |
|------|------|
| 找开头段 | 无代词、无连接词引用的段落 |
| 找结尾段 | 总结性语句的段落 |
| 建立连接 | 注意代词指代和逻辑连接词 |

> 💡 先确定首尾，再填充中间

@tab R-FIB

**Reading: Fill in the Blanks**

**评分规则**：
- 每个空格正确 +1 分
- 拖拽选项到正确位置
- **只贡献 Reading 分数**

**策略建议**：

| 技巧 | 说明 |
|------|------|
| 词性判断 | 根据语法判断空格需要的词性 |
| 语境推断 | 利用上下文语境选择 |
| 排除干扰 | 多余选项是干扰项，先排除 |

> 💡 先做有把握的空，再处理难的

@tab MC-SA

**Multiple Choice, Single Answer**

**评分规则**：
- 选对 +1 分
- 选错 0 分
- **只有一个正确答案**

**策略建议**：

| 原则 | 说明 |
|------|------|
| 时间分配 | 分值较低，不要花太多时间 |
| 排除法 | 快速排除明显错误选项 |
| 保守策略 | 不确定时选最保守的答案 |

> 💡 性价比最低的题型，快速完成即可

:::

### 阅读分数计算

PTE 阅读分数来源于以下题型：

```
Reading 分数 = RW-FIB + MC-MA + RO + R-FIB + MC-SA
```

**分数权重估计**（非官方）：

| 题型 | 权重估计 | 重要程度 |
|------|---------|---------|
| RW-FIB | ⭐⭐⭐⭐⭐ | 最高（双计分） |
| R-FIB | ⭐⭐⭐⭐ | 高 |
| RO | ⭐⭐⭐ | 中高 |
| MC-MA | ⭐⭐ | 中 |
| MC-SA | ⭐ | 低 |

### 时间分配建议

总时间：29-30 分钟

| 题型 | 建议时间 | 每题时间 |
|------|---------|---------|
| RW-FIB | 10-12 分钟 | 2 分钟/题 |
| MC-MA | 3-4 分钟 | 1.5 分钟/题 |
| RO | 6-8 分钟 | 2.5 分钟/题 |
| R-FIB | 6-8 分钟 | 1.5 分钟/题 |
| MC-SA | 2-3 分钟 | 1 分钟/题 |

::: danger 重要提醒
- 阅读和写作共享时间（29-30 分钟）
- 先做高分值题型（RW-FIB、R-FIB）
- 不要在 MC-SA 上花太多时间
- 宁可猜答案也不要超时
:::
