## Career Signaling 本质
```mermaid
flowchart LR
    subgraph A["不可见能力"]
        direction LR
        B1[智力]
        B2[毅力]
        B3[责任感]
    end

    B[可观察行为与成果<br/>Career Signaling]
    A -->|转化为| B
    
    class B signal
```

## Career Signaling实践

```mermaid
flowchart LR
    subgraph A["实践过程"]

        B2[思考什么]
        B3[怎么解决问题的]

    B[可观察行为与成果<br/>Career Signaling]
```

## 我的Portfolio
```mermaid
flowchart LR
    direction LR
    subgraph reason["学习期间"]
        subgraph Course["学习内容"]
          B1[教学中设计的算法]
          B2[数据结构与抽象概念]
        end
    
        Google[可复现的 Google Colab 代码<br> DrawIO的图像等]
        Forum[教学系统 Forum<br/>公开可观察]
        Pro[教授]
        E[邀请参与项目]
        F[获得项目报酬<br/>补贴部分学费]
    
        Course --> |转化为|Google
        Google --> |分享到| Forum
        Pro --> |观察到| Forum
        Pro --> |邀请| E
        E --> F
    end

    subgraph blog["产生了创建博客想法"]
        direction LR
        subgraph SkillStack["备选技术栈"]
          direction LR
          S1[Wordpress]
          S2[Vuepress]
          S3[博客平台]
        end
        
        subgraph CurrentBlog["当前博客"]
          direction TB
          vue[vuepress-theme-hope]
          jetblog[https://jet-w.github.io]
          problem[内存消耗指数型增长]
        end
        SkillStack --> |选择了| CurrentBlog
        vue --> |创建| jetblog
        jetblog --> |发现|problem
    end
    reason --> blog

```

## 我的新博客系统
```mermaid
flowchart LR
    direction LR
    subgraph reason["内存消耗原因"]
        vuepress["vuepress编译方式"]
    end

    subgraph backupstack["备用技术栈"]
        astro[Astro]
        astrobio[Astro生态]
        ret[无法找到合适的选项]
        astro --> |搜寻|astrobio
        astrobio --> |结果|ret
    end
    subgraph finalret["最终决定"]
      result[手搓一个博客系统]
    end
    reason --> backupstack
    backupstack --> finalret
```
