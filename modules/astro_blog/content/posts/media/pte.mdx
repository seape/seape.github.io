## Speaking 评分标准

### Read Aloud (RA) 评分标准

Read Aloud 是 PTE 口语部分最重要的题型，同时贡献 Speaking 和 Reading 分数。

#### 三个评分维度

| 维度 | 评分内容 | 最高分 |
|------|---------|--------|
| **Content（内容）** | 是否按顺序正确朗读每个单词 | 5 分 |
| **Pronunciation（发音）** | 发音是否接近母语者标准 | 5 分 |
| **Oral Fluency（流利度）** | 是否流畅、无不必要停顿或自我纠正 | 5 分 |

#### 评分细则

:::tabs
@tab Content 内容

**评分范围：0-5 分**

| 分数 | 标准 |
|------|------|
| **5 分** | 所有单词正确朗读，顺序正确 |
| **4 分** | 漏读/错读 1-2 个词 |
| **3 分** | 漏读/错读 3-4 个词 |
| **2 分** | 漏读/错读较多词 |
| **0 分** | 完全没读或全部错误 |

> 💡 按顺序读完所有单词即可得满分，跳过 1-2 个难词影响不大

@tab Pronunciation 发音

**评分范围：0-5 分**

| 分数 | 标准 |
|------|------|
| **5 分** | 所有元音、辅音发音准确，重音正确 |
| **4 分** | 大部分发音正确，少数错误不影响理解 |
| **3 分** | 部分发音有问题，但仍可理解 |
| **2 分** | 发音问题较多，理解困难 |
| **0 分** | 无法理解 |

> 💡 元音发饱满，辅音不吞音，注意单词重音和句子重音

@tab Oral Fluency 流利度

**评分范围：0-5 分**

| 分数 | 标准 |
|------|------|
| **5 分** | 语速自然，无明显停顿，节奏流畅 |
| **4 分** | 基本流畅，有少量犹豫 |
| **3 分** | 有明显停顿或重复 |
| **2 分** | 频繁停顿，语速不稳定 |
| **0 分** | 无法完成朗读 |

> 💡 保持自然语速，读错不要回读，根据意群合理停顿

:::

#### 分数贡献

Read Aloud 同时贡献两个分数：
- **Speaking 分数**：约占 25-30%
- **Reading 分数**：约占 20-30%

::: warning 2025年8月更新
根据 Pearson 2025 年 8 月 7 日的更新：
- Read Aloud 不再贡献 Reading 分数
- RA 的整体权重有所降低
:::

#### 实用技巧

::: tip 发音技巧
- 元音发饱满，辅音不吞音
- 该连读就连读
- 根据意群合理停顿
- 重读关键词（主语、谓语、宾语、状语）
:::

::: danger 避免扣分
- **不要回读**：读错了继续往下读
- **不要卡壳**：遇到生词根据拼读规则读出来
- **不要太快/太慢**：保持自然语速
- 跳过 5 个词以内通常不会严重影响分数（但要保持流利度）
:::

## Reading 评分标准

PTE 阅读部分包含多种题型，每种题型的评分方式不同。

### 题型与分值

| 题型 | 题目数量 | 评分方式 | 分值贡献 |
|------|---------|---------|---------|
| **Reading & Writing: Fill in the Blanks (RW-FIB)** | 5-6 题 | 部分得分 | Reading + Writing |
| **Multiple Choice, Multiple Answers (MC-MA)** | 2-3 题 | 部分得分（错选扣分） | Reading |
| **Re-order Paragraphs (RO)** | 2-3 题 | 部分得分 | Reading |
| **Reading: Fill in the Blanks (R-FIB)** | 4-5 题 | 部分得分 | Reading |
| **Multiple Choice, Single Answer (MC-SA)** | 2-3 题 | 全对得分 | Reading |

### 各题型评分细则

#### 1. Reading & Writing: Fill in the Blanks (RW-FIB)

**评分规则**：
- 每个空格正确 +1 分
- 错误或不填 0 分
- **同时贡献 Reading 和 Writing 分数**

::: tip 策略建议
- 这是最重要的阅读题型，同时影响两个分数
- 注意词性、搭配和语法
- 先看选项，再读文章
:::

#### 2. Multiple Choice, Multiple Answers (MC-MA)

**评分规则**：
- 选对一个 +1 分
- 选错一个 -1 分
- 最低 0 分（不会负分）

::: warning 注意
- 不确定的选项不要选
- 宁可少选，不要错选
- 通常正确答案 2-3 个
:::

#### 3. Re-order Paragraphs (RO)

**评分规则**：
- 按照相邻配对计分
- 每个正确的相邻配对 +1 分
- 例如：5 段文字，最多 4 个相邻配对，最高 4 分

::: tip 策略建议
- 找开头段（无代词、无连接词引用）
- 找结尾段（总结性语句）
- 注意代词指代和逻辑连接词
:::

#### 4. Reading: Fill in the Blanks (R-FIB)

**评分规则**：
- 每个空格正确 +1 分
- 拖拽选项到正确位置
- **只贡献 Reading 分数**

::: tip 策略建议
- 注意词性和搭配
- 利用上下文语境
- 多余选项是干扰项
:::

#### 5. Multiple Choice, Single Answer (MC-SA)

**评分规则**：
- 选对 +1 分
- 选错 0 分
- **只有一个正确答案**

::: note 提示
- 这题型分值较低，不要花太多时间
- 快速排除明显错误选项
- 如果不确定，选最保守的答案
:::

### 阅读分数计算

PTE 阅读分数来源于以下题型：

```
Reading 分数 = RW-FIB + MC-MA + RO + R-FIB + MC-SA
```

**分数权重估计**（非官方）：

| 题型 | 权重估计 | 重要程度 |
|------|---------|---------|
| RW-FIB | ⭐⭐⭐⭐⭐ | 最高（双计分） |
| R-FIB | ⭐⭐⭐⭐ | 高 |
| RO | ⭐⭐⭐ | 中高 |
| MC-MA | ⭐⭐ | 中 |
| MC-SA | ⭐ | 低 |

### 时间分配建议

总时间：29-30 分钟

| 题型 | 建议时间 | 每题时间 |
|------|---------|---------|
| RW-FIB | 10-12 分钟 | 2 分钟/题 |
| MC-MA | 3-4 分钟 | 1.5 分钟/题 |
| RO | 6-8 分钟 | 2.5 分钟/题 |
| R-FIB | 6-8 分钟 | 1.5 分钟/题 |
| MC-SA | 2-3 分钟 | 1 分钟/题 |

::: danger 重要提醒
- 阅读和写作共享时间（29-30 分钟）
- 先做高分值题型（RW-FIB、R-FIB）
- 不要在 MC-SA 上花太多时间
- 宁可猜答案也不要超时
:::
