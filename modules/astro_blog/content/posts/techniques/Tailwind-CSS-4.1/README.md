## 第 1 章：入门基础
学习目标：
1. 理解 Tailwind CSS 的设计理念和优势
2. 掌握 Tailwind CSS 4.1 的安装和基本配置
3. 了解实用优先（utility-first）的CSS方法论
4. 熟悉基本的类名规则和命名约定

简要说明：本章将带你从零开始认识 Tailwind CSS，了解其与传统 CSS 框架的区别，并完成开发环境的搭建。

## 第 2 章：核心工具类
学习目标：
1. 掌握布局相关的工具类（display、position、float等）
2. 熟练使用 Flexbox 和 Grid 布局工具类
3. 学会间距设置（margin、padding）和尺寸控制
4. 理解响应式设计的断点系统

简要说明：系统学习 Tailwind CSS 最常用的工具类，为后续复杂布局打下坚实基础。

## 第 3 章：样式与美化
学习目标：
1. 掌握颜色系统和自定义颜色配置
2. 学会字体、文本和排版相关工具类
3. 熟练使用边框、阴影和背景效果
4. 了解过渡和动画工具类的使用

简要说明：深入学习视觉效果相关的工具类，让你的网页更加美观和生动。

## 第 4 章：进阶特性
学习目标：
1. 掌握 @apply 指令的使用和最佳实践
2. 学会自定义工具类和组件抽取
3. 理解 JIT 模式和按需生成机制
4. 掌握 Tailwind CSS 4.1 的新特性和改进

简要说明：学习 Tailwind CSS 的高级功能，提高开发效率和代码可维护性。

## 第 5 章：配置与定制
学习目标：
1. 深入理解 tailwind.config.js 配置文件
2. 学会扩展默认主题和创建设计系统
3. 掌握插件系统的使用和开发
4. 了解生产环境优化和文件体积控制

简要说明：学会根据项目需求定制 Tailwind CSS，创建符合品牌风格的设计系统。

## 第 6 章：实战项目
学习目标：
1. 使用 Tailwind CSS 构建响应式登录页面
2. 开发现代化的个人作品集网站
3. 创建电商产品卡片和购物车界面
4. 实现复杂的仪表板布局设计

简要说明：通过实际项目练习，巩固所学知识，培养解决实际问题的能力。

## 第 7 章：框架集成
学习目标：
1. 在 React 项目中集成 Tailwind CSS
2. 在 Vue.js 项目中使用 Tailwind CSS
3. 与 Next.js 和 Nuxt.js 的集成配置
4. 学会在不同构建工具中的最佳实践

简要说明：学会在主流前端框架中使用 Tailwind CSS，适应不同的开发环境。

## 第 8 章：性能优化与最佳实践
学习目标：
1. 掌握 CSS 文件体积优化技巧
2. 学会合理组织和维护 Tailwind 代码
3. 了解可访问性（Accessibility）最佳实践
4. 掌握团队协作和代码规范制定

简要说明：学习生产环境下的优化策略和团队开发的最佳实践，确保项目的可维护性和性能。

## 第 9 章：扩展学习
学习目标：
1. 探索 Tailwind UI 组件库的使用
2. 学习 Headless UI 的集成方案
3. 了解 Tailwind CSS 生态系统和社区资源
4. 掌握故障排查和常见问题解决方法

简要说明：拓展知识边界，了解 Tailwind CSS 生态系统，为持续学习和技能提升做准备。
