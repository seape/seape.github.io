## 第 1 章：正则表达式入门
学习目标：
1. 理解正则表达式的基本概念和用途
2. 掌握正则表达式的基本语法结构
3. 学会使用在线工具测试正则表达式
4. 了解不同编程语言中的正则表达式支持

简要说明：介绍正则表达式是什么，为什么需要它，以及它在文本处理中的重要作用。

## 第 2 章：字符匹配基础
学习目标：
1. 掌握字面字符匹配
2. 理解和使用字符类 [abc]
3. 学会使用预定义字符类（\d、\w、\s等）
4. 掌握字符类的取反操作 [^abc]
5. 理解点号(.)的特殊含义

简要说明：学习最基础的字符匹配规则，这是构建复杂正则表达式的基石。

## 第 3 章：量词和重复
学习目标：
1. 掌握基本量词：*、+、?
2. 学会使用精确量词：{n}、{n,}、{n,m}
3. 理解贪婪匹配和非贪婪匹配的区别
4. 掌握非贪婪量词的使用：*?、+?、??

简要说明：学习如何控制匹配的次数和模式，这是正则表达式灵活性的关键。

## 第 4 章：位置匹配和边界
学习目标：
1. 掌握行首(^)和行尾($)锚点
2. 学会使用单词边界(\b)和非单词边界(\B)
3. 理解字符串开始(\A)和结束(\Z)位置
4. 掌握先行断言和后行断言的基本概念

简要说明：学习如何精确控制匹配的位置，避免误匹配。

## 第 5 章：分组和捕获
学习目标：
1. 理解分组的概念和语法()
2. 掌握捕获组的使用和引用
3. 学会使用非捕获组(?:)
4. 掌握命名捕获组的语法和应用
5. 理解反向引用的概念和使用

简要说明：学习如何将复杂的正则表达式分组管理，并提取所需的匹配内容。

## 第 6 章：高级断言技术
学习目标：
1. 深入理解正向先行断言(?=)
2. 掌握负向先行断言(?!)
3. 学会使用正向后行断言(?<=)
4. 掌握负向后行断言(?<!)
5. 理解断言的组合使用技巧

简要说明：掌握高级的位置匹配技术，实现更精确的模式匹配。

## 第 7 章：修饰符和模式
学习目标：
1. 掌握不区分大小写匹配(i)
2. 学会使用多行模式(m)
3. 理解单行模式(s)的作用
4. 掌握全局匹配(g)的使用
5. 了解其他常用修饰符的作用

简要说明：学习如何通过修饰符改变正则表达式的匹配行为。

## 第 8 章：实战应用场景
学习目标：
1. 编写邮箱地址验证的正则表达式
2. 实现电话号码格式匹配
3. 创建URL链接提取模式
4. 设计密码强度验证规则
5. 掌握日期时间格式匹配
6. 实现IP地址验证

简要说明：通过实际案例练习，将理论知识应用到常见的文本处理任务中。

## 第 9 章：编程语言中的正则表达式
学习目标：
1. 掌握JavaScript中的RegExp对象使用
2. 学会Python的re模块操作
3. 了解Java中的Pattern和Matcher类
4. 掌握PHP中的PCRE函数
5. 理解不同语言间的语法差异

简要说明：学习如何在主流编程语言中实际使用正则表达式。

## 第 10 章：性能优化和最佳实践
学习目标：
1. 理解正则表达式的执行原理
2. 掌握避免灾难性回溯的技巧
3. 学会编写高效的正则表达式
4. 了解正则表达式的调试方法
5. 掌握代码可读性和维护性的平衡

简要说明：学习正则表达式的高级优化技术和开发中的最佳实践。

## 第 11 章：文本处理综合实战
学习目标：

简要说明：通过综合项目实战，整合所学知识，解决实际的文本处理问题。
